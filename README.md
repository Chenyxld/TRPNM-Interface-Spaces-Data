# TR-PNM interface-space study: Python code and data

This repository accompanies *Effects of Interface Traction Spaces on Tensor Resistance-Based Pore-Network Flow*. It contains the independent Python Taylor–Hood Stokes implementation and archived results for the complete 16-pore particle domain. The experiment compares constant normal traction (P0n), two partial enrichments (P1n and P0nP0t), four normal/tangential polynomial modes (P1nP1t), and a finite-element trace reference. Each interface mode is paired with its velocity moment; physical boundary flow uses the outward normal.

## What is included

| Location | Contents |
| --- | --- |
| `src/ddpnm/` | Python geometry, Gmsh mesh, P2/P1 Stokes, local response and network assembly modules used by this study. |
| `experiments/tr_pnm/higher_order_interface/` | Python mesh generation, interface-space solves, checks and postprocessing. |
| `experiments/tr_pnm/interface_mode_ablation/` | Python code for the two intermediate interface spaces. |
| `experiments/tr_pnm/classical_dd/` | Python finite-element trace comparison. |
| `results/tr_pnm/higher_order_interface/A05/` and `A10/` | CAD, partitioned mesh, full-domain reference coefficients and both reduced-interface solutions at nominal mesh sizes 0.05 and 0.10. |
| `results/tr_pnm/higher_order_interface/A04/` and `A03/` | Verified summaries and error integrals for nominal mesh sizes 0.04 and 0.03. The full coefficient arrays for these two sizes are **not** in this repository. |
| `results/tr_pnm/interface_mode_ablation/` | Verified A05 summaries for P1n and P0nP0t; their full coefficient arrays are **not** in this repository. |
| `papers/tr_pnm_higher_order/` | Python programs that regenerate the published A05 plots and the four-mesh table rows from the archived outputs. |
| `SHA256SUMS` | Checksums of every packaged source and data file. |

The case uses the same particle CAD at all four mesh sizes. The interfaces, pore IDs and inlet/outlet labels are in `input/cad.json` and `input/partition.pkl` for A05 and A10. The binary `partition.pkl` files were created by this Python package; load them only from this trusted release. No MATLAB runtime or restricted finite-element package is needed.

The complete-domain reference at each mesh size uses the same physical geometry and boundary data. The A05/A10 archives include both the P2/P1 full-domain solution (`full2.npz`) and an independent P3/P2 full-domain solution (`full3.npz`). The table values at A04/A03 are supplied as checked numeric summaries. They can be regenerated by running the Python mesh and solve scripts in a new, empty working copy with adequate memory and disk space.

## Reproduce archived checks and figures

From the repository root, in a Python 3.11+ environment:

```bash
python -m pip install -e '.[figures,mesh]'
python scripts/verify_data.py
python papers/tr_pnm_higher_order/make_refinement_rows.py
python papers/tr_pnm_higher_order/plot_a05_fields.py
python papers/tr_pnm_higher_order/plot_a05_boundaries.py
```

The plot scripts write to `papers/tr_pnm_higher_order/figures/`. They evaluate saved FEM coefficients; they do not solve Stokes again. `make_refinement_rows.py` writes three LaTeX table fragments from the saved JSON results. Raw signed fluxes are retained in each `pore_*.npz` and in the method summaries. Pressure coefficients retain the traction-defined level.

## Recompute a case

To recompute, use a **fresh clone without the archived result directory for that case**; the scripts stop rather than overwrite a completed result. For example, after moving `results/tr_pnm/higher_order_interface/A05` out of a separate working copy:

```bash
python experiments/tr_pnm/higher_order_interface/case16.py A05
python experiments/tr_pnm/higher_order_interface/run.py A05 0
python experiments/tr_pnm/higher_order_interface/run.py A05 1
python experiments/tr_pnm/higher_order_interface/audit_errors.py A05 --output results/tr_pnm/higher_order_interface/recomputed_A05_errors.json
```

Mesh generation needs Gmsh. The full-domain higher-order solve and local responses are computationally demanding. Run them on a suitable compute node. `case16.py` writes the CAD and mesh before the method-specific runs. For P1n or P0nP0t, use `experiments/tr_pnm/interface_mode_ablation/ablate.py A05 P1n` or `... A05 P0nP0t` after the P1nP1t result exists.

## Reproducibility scope

`scripts/verify_data.py` verifies file hashes, the four-mesh summary table, the A05 local field arrays, and the signed outlet-flow calculation. It does not claim to validate a new numerical solve. The archived A04/A03 fields and the A05 intermediate-mode fields are unavailable locally, so those full-field figures cannot be regenerated from this release alone. The corresponding numerical summaries are clearly marked as such. No new FEM computation or neural-network training was performed to make this repository.
